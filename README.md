# hxyfront-62009 地毯修复 · 回传对账工作台

源提示词编号：2

总店常把清洗和补线交给合作工坊，对方回传施工记录后，修复档案与实际用线对不上、
结算重复扣线。本项目把**修复档案、破损框、补线色卡**三本底账接成「回传对账」流程。

## 对账规则

1. **合并键**：地毯编号 + 破损框 + 工序，档案记录与工坊回传按此合并。
2. **两版留档**：同一处两边都改过且不一致时，档案版、工坊实测版都保留为「两版待确认」，
   后到的记录追加留档，**绝不覆盖先到的**，由人工选择一版结算。
3. **确认后才扣线**：确认时按**实测用量**扣一次补线色卡；清洗/固色等无耗材工序不扣。
4. **重复回传幂等**：同工坊回执号（returnId）再次到达只登记拦截，不覆盖留档、不扣第二遍；
   色卡扣减台账按合并键兜底，重复确认同样拒绝。
5. **库存不足失败不扣**：实测用量超过色卡库存时确认失败、不扣减，补线入库后可重试。
6. **断点续对**：对账中断时已确认的地毯成果全部保留并落断点，恢复后**只续做没对上的**项，
   已确认项不重跑、不二次扣线。
7. **孤儿记录**：地毯编号或破损框在总店底账不存在时挂起，不参与确认。

## 页面构成

- 回传批次接收（含重复回传、库存不足、孤儿编号等场景数据）
- 自动对账（可演练「确认 2 项后故障中断 → 恢复续对」）
- 对账明细：两边版本对照、人工裁决确认
- 补线色卡库存与补线入库
- 色卡扣减台账（每处一笔）与重复回传拦截列表
- 操作与对账流水（localStorage 持久化，刷新后状态保留）

## 技术栈

React 19 + Vite + TypeScript，纯函数对账引擎位于 `src/recon/engine.ts`。
